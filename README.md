# ระบบบริหารจัดการงานสหกิจศึกษา (Cooperative Education System)

โปรเจคจบการศึกษา (ภาคนิพนธ์) มหาวิทยาลัยเทคโนโลยีราชมงคลตะวันออก (RMUTTO)

เว็บแอปพลิเคชันสำหรับดำเนินงานและติดตามงานสหกิจศึกษา ตั้งแต่นักศึกษายื่นคำร้องขอหนังสือ
ไปจนถึงการประเมินผลหลังสิ้นสุดการปฏิบัติงาน

> **สถานะ:** อยู่ระหว่างพัฒนา ยังไม่ได้นำขึ้นใช้งานจริง

## ผู้ใช้งาน

- **นักศึกษา** — ยื่นคำร้อง กรอกแบบฟอร์มสหกิจ บันทึกการปฏิบัติงาน ส่งรายงาน และดูผลประเมิน
- **เจ้าหน้าที่สหกิจ** — ตรวจคำร้อง ออกหนังสือ ดูแลปฏิทินสหกิจและข้อมูลผู้ใช้
- **อาจารย์ที่ปรึกษา / อาจารย์นิเทศ** — ติดตามนักศึกษา ตรวจโครงร่างและรายงาน นัดหมายและบันทึกการนิเทศ
- **หัวหน้าสาขาวิชา** — มอบหมายอาจารย์ที่ปรึกษาและอาจารย์นิเทศ
- **คณบดี** — ลงนามหนังสือราชการด้วยลายมือชื่อดิจิทัล
- **พี่เลี้ยง (พนักงานที่ปรึกษา)** — รับรองบันทึกการปฏิบัติงาน ตรวจโครงร่างรายงาน และประเมินนักศึกษา
- **สถานประกอบการ** — ตอบรับหรือปฏิเสธนักศึกษาผ่านลิงก์ในอีเมล โดยไม่ต้องมีบัญชี

## เทคโนโลยี

- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **Backend:** Node.js, Express, TypeScript, PostgreSQL
- **การทดสอบ:** Playwright (End-to-End)

## โครงสร้าง

```
backend/    API และฐานข้อมูล
frontend/   หน้าเว็บ
e2e/        ชุดทดสอบอัตโนมัติ
```

## การทดสอบ

ชุดทดสอบอัตโนมัติอยู่ใน `e2e/` เขียนด้วย Playwright มากกว่า 500 เทสต์
แบ่งโฟลเดอร์ตามกลุ่มผู้ใช้ เส้นทางงานที่เดินข้ามหลายฝ่าย และความปลอดภัยของข้อมูล
