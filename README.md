# Online Cooperative Education Management System

ระบบสารสนเทศเพื่อการบริหารจัดการงานสหกิจศึกษา มหาวิทยาลัยเทคโนโลยีราชมงคลตะวันออก (RMUTTO)
ระบบนี้ได้รับการพัฒนาขึ้นมาเพื่อควบคุมและบริหารจัดการขั้นตอนการดำเนินงานสหกิจศึกษาสำหรับนักศึกษา อาจารย์ เจ้าหน้าที่ และสถานประกอบการอย่างเป็นขั้นตอนและปลอดภัย

## 📂 โครงสร้างของโปรเจกต์ที่จัดระเบียบใหม่ (Project Directory Structure)

โปรเจกต์นี้ได้รับการจัดโครงสร้างในรูปแบบ Monorepo / Workspace Orchestrator เพื่อการพัฒนาและดูแลระบบที่สะดวกและชัดเจน:

```
Cooperative Education System/
├── backend/                   # บริการระบบหลังบ้าน (Express Backend API)
│   ├── src/                   # โค้ดโปรแกรมหลัก (TypeScript)
│   │   ├── config/            # การกำหนดค่าเชื่อมต่อฐานข้อมูล
│   │   ├── controllers/       # ตัวรับและจัดการคำขอเส้นทาง (Controllers)
│   │   ├── db/                # สคริปต์โครงสร้างตาราง (Schema) และข้อมูลจำลอง (Seeds)
│   │   ├── middlewares/       # ตัวกรองข้อมูลความปลอดภัย (Auth, RBAC, File Uploads)
│   │   ├── models/            # โมเดลธุรกรรมฐานข้อมูล (Models)
│   │   └── routes/            # ตัวรับเส้นทาง API (Routes)
│   ├── uploads/               # โฟลเดอร์เก็บเอกสารและประวัติผู้สมัครงาน (Git-ignored)
│   ├── secure_private/        # พื้นที่ปลอดภัยสำหรับเทมเพลต PDF และภาพลายเซ็น
│   └── package.json           # การตั้งค่า dependencies ของ Backend
├── frontend/                  # บริการหน้าบ้าน (Vite + React SPA)
│   ├── src/                   # ไฟล์หน้าเพจ ส่วนควบคุมสถานะ (Contexts) และคอมโพเนนต์ React
│   └── package.json           # การตั้งค่า dependencies ของ Frontend
├── package.json               # Root Workspace Orchestrator (รันคำสั่งทั้งหมดจากโฟลเดอร์หลัก)
└── README.md                  # เอกสารแนะนำการติดตั้งและพัฒนาโปรเจกต์
```

## คุณสมบัติของระบบที่พัฒนาเสร็จสิ้น (Phase 1)

ระบบได้รับการพัฒนาแบบ Full-stack โดยเชื่อมโยงระหว่างส่วนหน้าบ้านและส่วนหลังบ้านด้วยโครงสร้างความปลอดภัยและการจัดการบทบาทที่เข้มงวด

### 1. ระบบหน้าบ้าน (React Frontend SPA)
พัฒนาโดยใช้เทคโนโลยี Vite + React + TypeScript + TailwindCSS v4 + Radix UI
* **ระบบการลงทะเบียนครั้งแรก (Onboarding Guard):** ตรวจจับสถานะการเข้าใช้งานครั้งแรก หากผู้ใช้ยังไม่ได้กำหนดประวัติ จะถูกบังคับให้กรอก รหัสนักศึกษา/สาขาวิชาก่อนเข้าสู่ระบบ Dashboard
* **หน้าแดชบอร์ดตามบทบาทผู้ใช้งาน (Role-Based Dashboards):**
  * **บทบาทนักศึกษา:** แสดงสถานะผ่านเครื่องมือ Milestone Progress Tracker ค้นหางานผ่านกระดานอัจฉริยะ (Smart Job Board) ร่วมกับแผนที่ Google Maps รองรับการดาวน์โหลดใบยินยอมผู้ปกครองแบบพิมพ์ข้อมูลมาแล้ว (Pre-filled PDF) และอัปโหลดไฟล์เข้าระบบ
  * **บทบาทอาจารย์ที่ปรึกษา:** หน้าพิจารณาอนุมัติการยื่นความจำนงของนักศึกษาในสังกัด โดยมีตรรกะล็อกปุ่มอนุมัติหากนักศึกษยังไม่ได้อัปโหลดใบยินยอมผู้ปกครอง
  * **บทบาทหัวหน้าสาขาวิชา:** หน้าจอสำหรับมอบหมายและสลับตัวอาจารย์ที่ปรึกษา/อาจารย์นิเทศแบบรายบุคคลหรือแบบกลุ่ม (Batch Assignment)
  * **บทบาทคณบดี:** แผงจัดการลายเซ็นดิจิทัลผ่าน Canvas (E-Signature Pad) และระบบอนุมัติลงนามหนังสือขอความอนุเคราะห์และส่งตัวนักศึกษาแบบกลุ่ม (Batch Signing) พร้อมหน้าต่างแสดงตัวอย่างเอกสาร PDF
  * **บทบาทเจ้าหน้าที่สหกิจ:** หน้าจอนำเข้ารายชื่อนักศึกษาผ่านการลากวางไฟล์ CSV/Excel (Drag-and-drop Import) ด้วย SheetJS พร้อมระบบออกจดหมายราชการโดยดึงพิกัดลายเซ็นและการจัดหน้าจากฝั่งหลังบ้าน
  * **บทบาทสถานประกอบการ:** หน้าจอสำหรับประกาศตำแหน่งงานใหม่ ตรวจสอบและอนุมัติผู้ยื่นใบสมัคร ระบุรายละเอียดพี่เลี้ยง (Mentors) หรือตอบปฏิเสธใบสมัครพร้อมชี้แจงเหตุผล

### 2. ระบบหลังบ้าน (Express Backend API)
พัฒนาโดยใช้ Node.js + Express + TypeScript + PostgreSQL
* **ระบบความปลอดภัย (Security & Auth):** จัดการสิทธิ์การเข้าถึงผ่าน JWT Token และการดักกรองด้วย Middleware (RBAC Authorization) พร้อมการป้องกันการดาวน์โหลดประวัตินักศึกษาข้ามสถานประกอบการ
* **ระบบจัดการเอกสารราชการอัตโนมัติ:** นำเข้าไลบรารี `pdf-lib` และ `@pdf-lib/fontkit` สำหรับวาดลายเซ็นคณบดีและประทับข้อมูลส่วนบุคคลลงบนหนังสือยินยอมผู้ปกครองแบบไดนามิก โดยดึงข้อมูลจากฐานข้อมูลมาพิมพ์ลงแบบฟอร์มด้วยฟอนต์ราชการไทย (Srabun-Regular)
* **ระบบนำเข้าและตรวจสอบข้อมูล:** รองรับการประมวลผลการนำเข้ารายชื่อผู้ใช้จาก CSV แบบสตรีม และการตรวจสอบข้อมูลเกรดเฉลี่ยขั้นต่ำเพื่อเข้าร่วมสหกิจศึกษา

## ขั้นตอนการติดตั้งและการใช้งานระบบ

การรันโปรเจกต์นี้ แนะนำให้รันคำสั่งทั้งหมดจากโฟลเดอร์หลักของโปรเจกต์ (Root Workspace) เพื่อความสะดวก

### 1. ข้อกำหนดเบื้องต้น
* Node.js (เวอร์ชัน 18 หรือสูงกว่า)
* PostgreSQL (ระบบฐานข้อมูลที่ติดตั้งและเปิดใช้งานอยู่บนเครื่อง)

### 2. การตั้งค่าตัวแปรสภาพแวดล้อม (Environment Variables)
คัดลอก `backend/.env.example` เป็น `backend/.env` แล้วเติมค่าให้ครบ:
```bash
cp backend/.env.example backend/.env
cp frontend/.env.example frontend/.env
```

```env
PORT=5000
DB_HOST=localhost
DB_PORT=5432
DB_USER=your_postgres_username
DB_PASSWORD=your_postgres_password
DB_DATABASE=coop_edu_db
JWT_SECRET=<ต้องสุ่มเอง — ห้ามใช้ค่าตัวอย่างซ้ำ>
JWT_EXPIRES_IN=24h
```

> ⚠️ **JWT_SECRET ต้องสุ่มใหม่เสมอ และห้าม commit ลง repo**
> ผู้ที่รู้ค่านี้สามารถปลอม token เป็นบทบาทใดก็ได้ (รวมถึงคณบดี) สร้างค่าด้วย:
> ```bash
> node -e "console.log(require('crypto').randomBytes(64).toString('hex'))"
> ```
> เซิร์ฟเวอร์จะไม่ยอมสตาร์ทถ้าไม่ได้ตั้งค่านี้

### 3. การติดตั้ง Dependencies ของโปรเจกต์
เปิด Terminal ในโฟลเดอร์หลักของโปรเจกต์แล้วรันคำสั่ง:
```bash
# 1. ติดตั้ง dependencies หลักของเครื่องมือรันการทดสอบและสคริปต์จัดระบบ
npm install

# 2. ติดตั้ง dependencies สำหรับระบบหลังบ้าน (Backend Server)
npm install --prefix backend

# 3. ติดตั้ง dependencies สำหรับระบบหน้าบ้าน (Frontend Web)
npm install --prefix frontend
```

### 4. การเตรียมฐานข้อมูลและใส่ข้อมูลเริ่มต้น (Seed Data)
รันสคริปต์เพื่อสร้างตารางทั้งหมด ตลอดจนเพิ่มวิชา สาขา และบัญชีทดสอบในระบบโดยใช้คำสั่ง:
```bash
npm run db:setup --prefix backend
```

### 5. การเปิดใช้งานระบบเพื่อทดสอบ
สามารถรันบริการทั้งหน้าบ้านและหลังบ้านผ่าน Terminal 2 บานแยกจากกันในโฟลเดอร์หลักได้ทันที:

* **รันบริการระบบหลังบ้าน (Backend Server):**
  ```bash
  npm run dev:backend
  ```
  บริการหลังบ้านจะเปิดทำงานที่ `http://localhost:5000`

* **รันบริการระบบหน้าบ้าน (Frontend Web Dev Server):**
  ```bash
  npm run dev:frontend
  ```
  บริการหน้าบ้านจะเปิดให้เข้าใช้งานที่ `http://localhost:5173`
